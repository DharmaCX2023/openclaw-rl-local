## 留在本地、由 Git 忽略

- 训练输出、准备好的 SFT／smoke 数据、本地虚拟环境与缓存。
- 模型权重、tokenizer／权重软链接；单独保留的模型配置不构成完整可运行模型。
- `.env` 等凭证文件、日志、`.orig` 等备份。
- 旧 smoke 归档、汇报 ZIP、完整包校验清单、大型研究 PPT 原稿。
- 可由分析脚本重新生成的逐 step／segment／token 明细及大型审计 JSON。

忽略不等于删除或备份。以上文件仍保留原位置；Git clone 不会恢复它们。正式报告中的本地原始证据链接仍可能需要原 outputs／归档目录，报告打包脚本也需要这些数据。报告的小型配图已保留入库。
